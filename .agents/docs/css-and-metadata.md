Editing rules for [`cleome/_font/metadata.py`](../../src/cleome/_font/metadata.py), [`cleome/_names.py`](../../src/cleome/_names.py), [`cleome/_output/paths.py`](../../src/cleome/_output/paths.py), [`cleome/_output/css.py`](../../src/cleome/_output/css.py), and [`cleome/_pipeline.py`](../../src/cleome/_pipeline.py). See [`docs/architecture-and-rationale.md`](../../docs/architecture-and-rationale.md) for background rationale, [`docs/hosting-and-usage.md`](../../docs/hosting-and-usage.md) for output layout and caching behavior, and [`skills/cleome/SKILL.md`](../../skills/cleome/SKILL.md) for the public API contract.

## Variable and static axis mapping

* Extract family names (including Windows BMP `(3, 1, 0x0409)` and UCS-4 `(3, 10, 0x0409)` `name` records) and `font-weight`, `font-stretch`, and `font-style` from `fvar` (`wght`, `wdth`, `ital`, `slnt`) for variable fonts and from `OS/2` (including `fsSelection` bit 9 `OBLIQUE` and bit 0 `ITALIC`) and `post` for static fonts (`extract_font_face_descriptors` in `cleome/_font/metadata.py`).
* In `extract_font_face_descriptors` (`cleome/_font/metadata.py`), include `"normal"` in `styles_css` (which `generate_css` in `cleome/_output/css.py` expands into `@font-face` rules) only when the font's axis ranges include an upright form (`ital < 0.5` when `ital` is present and `0deg` within `slnt` when `slnt` is present), alongside `"italic"` (`ital >= 0.5`) and `"oblique <min>deg <max>deg"` (`slnt != 0`).

## Multi-font variant bundling and output integrity

* Raise a `ValueError` in `validate_and_compute_variant_suffixes` (`cleome/_font/metadata.py`) on `font-family` mismatches (unless overridden), semantically equivalent `(font-weight, font-stretch, font-style)` collisions (using exact `Decimal` precision for finite values so `400` and `400.000001` remain distinct, normalizing `normal` == `400`, `bold` == `700`, omitted / `normal` == `100%` and CSS width keywords `ultra-condensed` `50%` .. `ultra-expanded` `200%`, `oblique 0deg` / `0rad` / `0grad` / `0turn` == `normal`, degree-normalized `<angle>` units, 2-value range bounds, and finite constant-folded `calc(...)` literals while preserving general or non-finite Stixis-validated CSS math expressions such as `min(...)`, `clamp(...)`, `calc(infinity)`, and `calc(nan)`), or duplicate `variant_suffix` values rather than auto-numbering colliding variants (`-2`, `-3`).
* Format collision-free variant filename suffixes with `"-"` between `(stretch, weight, styles)` slots (`400`, `700`, `w75-400`, `400-italic`), `"_"` inside multi-token range or angle axes (`w75_100-400` vs `w75-100_400`, `oblique_0deg_12deg`), `"p"` for decimals (`w62p5`), and `"neg"` for negative angles (`oblique_neg12deg`), and validate planned slice filenames in `_prepare_font_bundle` (`cleome/_plan/bundle.py`).
* Reject scalar single-font `weight`, `stretch`, or `style` overrides across 2 or more input fonts in `slice_fonts` (`cleome/_pipeline.py`) and `cleome plan` / `cleome build` (`cleome/cli.py`) with `ValueError` (`Cannot apply single-font descriptor override ...`).
* Build and export each bundled variant's slices from its own mapped codepoints (`variant_slice_specs`) rather than the cross-font union.
* In `slice_fonts` (`cleome/_pipeline.py`), collect `.woff2` slice filenames recorded in the pre-existing `css_path`, sibling Cleome stylesheets, and per-`slices_dir` registered external `css_path` owners via `_read_cleome_css_bundle_slices` (`cleome/_output/css.py`) and prune superseded or orphaned slices via `_prune_superseded_hashed_slices` (`cleome/_font/subset.py`) only after the new CSS file has been written atomically (preserving slices belonging to other font slugs in a shared `slices_dir`, including slugs like `example-400` alongside `example` and external `--css-out` / `css_path` stylesheets), and verify the exact stylesheet-recorded `.woff2` filenames and SHA-256 content hashes in `_try_load_cached_bundle` via `_parse_cleome_css_bundle` (skipping the `slices_dir` existence check when `active_variant_plans` has no active slices, such as empty-`cmap` fonts).
* Keep `css_filename` and `css_path` mutually exclusive across `slice_font`, `slice_fonts`, and `cleome/cli.py`.
